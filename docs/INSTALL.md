# 📥 Installation de PatSecure

## Prérequis

- Deepin Linux 25 ou version ultérieure
- Droits administrateur (sudo)

## Installation

Clonez le dépôt :

```bash
git clone https://github.com/PattooDev/PatSecure.git
```

Accédez au dossier :

```bash
cd PatSecure
```

Rendez le script exécutable :

```bash
chmod +x patsecure.sh
```

Lancez PatSecure :

```bash
./patsecure.sh
```

## Mise à jour

Pour récupérer la dernière version :

```bash
git pull
```
